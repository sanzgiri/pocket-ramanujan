# Pocket Ramanujan

A static-first web guide to important mathematical ideas associated with Srinivasa Ramanujan.

## Development

```bash
npm install
npm run dev
```

Build and preview the production site:

```bash
npm run check
npm run build
npm run preview
```

The content is authored as version-controlled Markdown/MDX and will use KaTeX-rendered mathematics as the collection is added. The project intentionally excludes the 1729 anecdote from the discovery collection.
